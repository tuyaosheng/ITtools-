# ITtools 信息技术教学平台 使用说明书

> 本文件是 Word 版 `docs/ITtools使用说明书.docx` 的文字来源，改内容时两边一起更新。

## 一、概述与登录

ITtools 是给信息技术课用的教学平台，分管理员、教师、学生三种角色，三种角色登录后进入各自的后台。浏览器打开平台地址（默认端口 8300）就是登录页。

### 三种角色

| 角色 | 主要工作 | 登录后进入 |
| --- | --- | --- |
| 管理员 | 建年级和班级、导入师生、配置机房、设学期、系统设置 | 管理后台 |
| 教师 | 备课、上课、课堂互动、批作业、出题考试、看学情 | 教师工作台 |
| 学生 | 进课堂学习、交作品、做测验和练习、用网盘和笔记 | 信息课堂 |

### 登录方式

- **学生 · 班级姓名**：选学年、班级、自己的名字，再输密码。
- **学生 · 学号**：输学号和密码。
- **教师 / 管理员**：输账号和密码。
- 登录页显示哪些入口，由“系统设置 → 工作模式”决定：学号模式只显示学号入口；其他模式显示班级姓名入口。
- 学生只能用一种角色入口；进错角色的页面会自动跳回自己的首页。

### 默认密码

| 账号 | 默认密码 | 说明 |
| --- | --- | --- |
| 管理员 admin | admin123 | 初次部署后请立即在右上角“修改密码”中改掉 |
| 学生、教师（新建或导入时没填密码） | 123456 | 管理员可在“用户管理”里逐个重置密码 |

右上角头像菜单里有“个人资料”“修改密码”“退出登录”。学生能否自己改密码、传头像，由系统设置控制。

### 第一次使用的顺序

1. 管理员在“年级管理”建学年（如 2024 级）。
2. 在“班级管理”建班级，或直接用“批量导入”导入学生，年级和班级会自动建好。
3. 在“批量导入”导入教师账号。
4. 在“教学管理”建学期并设为当前学期，把班级绑定给任课教师。
5. 机房上课需要固定座位、开断网的，再配置“机房管理”下的四项。
6. 教师登录，建课程、加页面，然后开课上课。

## 二、管理员 · 师生与班级

这一组菜单管学年、班级和所有账号。新学年开学时，一般只要用“批量导入”导一次学生名单。

### 年级管理

- 每个学年有“学年代码”（入学年份，如 2024）和“学年名称”（如 2024级）。
- 状态设为“停用”后，这个年级不再出现在登录页和教师的班级列表里。
- 年级下还有班级或学生时不能删除。

### 班级管理

- 先在顶部选学年，再新增、编辑、删除班级。
- “排序”决定班级在全系统各处的先后次序，数字小的在前。新增班级时默认排在本年级最后。
- 批量导入自动建的班级，排序取班名里的数字（“3班”排 3）。

### 用户管理

- 列表每页 50 条（可切换 20 / 100 / 200），可按角色、学年、班级筛选，或输姓名 / 学号 / 登录名搜索。
- 新增学生必填姓名和学号；学号全校唯一，学生可用学号登录。班内学号是座号，填正整数，可不填。
- 新增教师、管理员要填登录名。
- 每行可以：编辑、重置密码（至少 6 位）、删除；“毕业”“启用”开关点一下就生效。
- 已经有课程、作业等教学记录的账号不能删除，只能关掉“启用”。

### 批量导入

1. 点“下载模板”，按模板填表，支持 .xlsx / .xls / .csv。
2. “选择文件”后点“开始导入”。
3. 页面先显示上传百分比，再显示“正在导入 已处理 / 总行数（成功、失败）”的进度条。
4. 导入完成后显示“共 N 行，成功 X，失败 Y”，下面列出每个失败行的行号和原因。改好这几行可以单独再导一次。

| 导入对象 | 必填列 | 可选列 | 注意 |
| --- | --- | --- | --- |
| 学生 | 姓名、学号、年级码（如 2024）、班级（如 1班） | 班内学号、初始密码 | 年级、班级不存在会自动建；学号不能重复；同班不能同名 |
| 教师 | 姓名、登录名 | 初始密码 | 登录名不能重复 |

初始密码留空就是 123456。整个文件出错（例如表头不对）时会显示红色提示，这种情况下一条数据都没有写入。

### 学生数据维护

- **表格批量修改**：选年级 → 下载学生信息表 → 在表里改姓名、学号、班内学号、性别、班级（重新分班）、入学年份或毕业状态 → 上传。系统先列出改动预览，确认后才写入。“编号”列用来对应学生，不要改。
- **批量导入头像**：学生照片按学号命名、教师照片按登录名命名，打成 zip 上传，支持 JPG / PNG / GIF / BMP。结果会列出成功张数和没匹配上的文件名。
- **毕业生管理**：勾选班级后“设为毕业”或“恢复在读”。毕业生不能再登录，也不出现在名单、课堂和报表里。
- **释放资源空间**：删除所选班级毕业生的全部学习记录和文件，只保留账号和精华作品。不可恢复，操作前请先备份数据库。

## 三、管理员 · 机房管理

机房管理的四项按顺序配置：先登记机位（每台电脑），再排机房座位图，再分小组，最后给班级绑定机房和固定座位。不用固定座位、不用开断网的学校可以跳过这一章。

### 机位管理

- 每个机位 = 一台电脑，记录“计算机名”（如 PC-01）和“IP 地址”。
- 可以逐台新增，也可以“下载导入模板”后“批量导入”。导入时可以勾选“导入前清空已有机位”。
- 学生登录时系统按电脑 IP 认出机位，课堂里会显示“机位：PC-xx”。

### 机房模型（座位图）

- **按方案新建**（推荐）：填机房名称、座位名前缀（如 A 或 PC-）、编号位数、1 号座位 IP 和递增/递减方向，再填“共几排、每排几台、每几台留一个过道”和 1 号的位置，点“按这些生成排版”。
- 生成的“排版文本”可以直接改：座位号写数字，过道写 `.`，可以删掉坏机位。下方有预览，最多 40 排、每排 40 个位置。
- **空白新建**：只设行数、列数，再点“调整机位”逐格选电脑，或“按计算机名自动排布”。
- 座位图平时只看；点“管理”后可以点选多个座位，批量“暂停网络 / 恢复网络”；选中两台时可以“交换这两台的 IP”（电脑实际位置和 IP 对不上时用）。
- 开断网和开机状态需要先在“系统设置 → 网络控制器”启用。座位上的 🌐/⛔ 是平台最后一次下发的指令，不是实时探测。

### 分组模型

- 把机房里的机位分成若干小组，教师上课时选一个分组模型，学生进课后按自己坐的电脑自动分到对应小组。
- 新增一个分组模型后，填“每组几台”点“自动分组”，也可以在表格里逐台改组号，最后“保存”。

### 固定机位

- 每个班级选“上课机房”，再点“分配座位”给每个学生定一个座位。
- “按班内学号自动分配”会按座号顺序排满，“全部清空”重来。
- 只有系统设置里的工作模式是“班级+姓名+固定机位模式”时，已分配座位的学生才必须在自己的座位上登录。

## 四、管理员 · 系统

开学前必须做的是“教学管理”里的学期和班级绑定；其余项目按需要设置。

### 教学管理

- **学期维护**：新增学期（学年如 2025-2026，学期如 第一学期），点“设为当前”。之后开的课都记在当前学期下，报表按学期筛选。
- **班级绑定教师**：给每个班级选任课教师。教师能开课、看学情的班级 = 绑定给自己的班级 + 还没绑定任何教师的班级；绑给别的老师的班级看不到。
- **当前课堂**：列出正在进行的课（课程、教师、开始时间、出席人数），可以对单个课堂“强制下课”。

### 走班选课

1. “新建选课活动”：填名称、说明，选面向的年级，再逐个“添加科目”（科目名、人数上限、任课教师、上课时间、简介）。
2. 新建后是“草稿”，点“开放选课”后学生在“走班选课”里选、退选、改选，满额的科目选不了。
3. 点“结束选课”后名单固定；“名单”查看、“导出”得到 Excel。

### 权限管理

按模块列出系统权限（如用户管理、班级管理、年级管理、权限管理），可以逐项关闭。一般保持全部开启即可。

### 系统设置

| 分组 | 设置项 | 说明 |
| --- | --- | --- |
| 基本 | 学校名称 | 显示在登录页和各端左上角 |
| 基本 | 工作模式 | 正常教学：班级+姓名+密码登录；公开课：学生登录后直接进入当前课堂；学号+密码：只显示学号登录；固定机位：已分配座位的班级必须在自己的座位登录 |
| 文件 | 禁止上传的扩展名 | 逗号分隔，如 exe,bat |
| 文件 | 单文件上限、学生网盘容量 | 单位 MB |
| 文件 | 学生单处登录 | 开启后同一个学生在另一台电脑登录时，前一台会被挤下线 |
| 教学 | 允许作业补交 | 下课后学生还能交作品，标记为“补交” |
| 教学 | 敏感词过滤 | 多个用逗号分隔 |
| 登录页与学生权限 | 登录页公告、学生改密码、学生传头像 | 开关控制学生能否自己改 |
| 第三方程序登录 | 开启、签名密钥 | 其他系统带签名链接让学生免密登录；链接 5 分钟内有效且只能用一次，生成新密钥后旧密钥立即失效 |
| 网络控制器（CTR） | 启用、控制器地址、访问令牌 | 启用后机房座位图能批量开网 / 断网。控制器和平台在同一台电脑时地址填 http://127.0.0.1:8770；不在同一台时填 http://控制器电脑IP:8770，并把控制器的控制接口地址（api_host）改成 0.0.0.0、那台电脑防火墙放行 8770、两边填同一个令牌；点“保存并测试连接”会显示被控端台数和在线台数 |

改完点“保存设置”才生效。

### 应急工具（操作不可撤销）

| 工具 | 什么时候用 |
| --- | --- |
| 全部强制下课 | 正常下课和单个强制下课都不管用时，把所有进行中的课堂一次关掉；没进课的学生记为缺席 |
| 消除缺勤记录 | 学生补了假条、或后来才转入本班：选年级、班级查询后勾选缺席 / 请假记录删除，这节课不再计入出勤统计 |
| 学期修复 | 调整过学期后，有些课堂没归到任何学期，报表按学期查不到：查出这些课堂，指定学期 |
| 强制删除课程 | 删除已经开过课的课程，连同全部课堂和学习记录（考勤、作品、测验）。教师自己只能删没开过课的课程。删前先备份数据库 |

## 五、教师端

教师的日常是三步：在“我的课程”备课，点“开课”进入课堂控制台上课，下课后在“作品批阅”“作业与测验”“学习情况”里收尾。

### 工作台

- 显示当前学期、正在进行的课堂、最近上课记录和今日课表。
- “开 课”：选课程、上课班级、分组模型（可不分组），点“开始上课”。
- 课表在“课表”菜单里编辑：按星期和节次填写（如班级名），节数可调，保存后工作台显示当天的课。

### 我的课程（备课）

1. “新建课程”，在“属性”里设分类、学期、简介，打开“共享”后其他老师能在“共享课程 / 模板”里看到并“以此为模板新建”。
2. 进入课程，“添加页面”，选页面类型、填标题和内容，“保存页面”后再上传附件或做专属设置。
3. 勾选“默认隐藏”的页面，上课时要教师手动打开学生才看得到。
4. 课程可以“复制”“导出”（课程包），也可以“导入课程包”。没开过课的课程可以删除。

| 页面类型 | 用途 |
| --- | --- |
| 图文 | 文字、图片等学习内容 |
| 资料课件 | 上传 PPT / PDF / 文档供学生查看下载 |
| 视频 | 上传视频或填视频地址 |
| 外部网页 | 嵌入或打开一个网址 |
| 作品提交 | 学生上传作品，可自动评分、互评 |
| 课堂测验 | 关联题库试卷，学生在线作答、自动批改 |
| 讨论 | 按小组讨论并提交小组结论 |
| 抢答 | 教师发起抢答，学生抢先作答，教师判定对错 |
| Python 操作题 | 学生在线写 Python，按测试点自动评分 |
| 分组与组长 | 学生自由选小组、推选组长 |
| 小组合作 | 研究主题、组内分工、资源交流、组员互评，组长提交成果 |
| 小组成果展示 | 展示各组成果，组间互评 |
| 课堂调查 | 判断 / 单选 / 多选 / 填空调查，实时统计全班和年级结果 |
| 随机抽题 | 学生随机抽一道问题，相邻座号的同学题目不同 |
| 课件包 | 上传 Storyline 等发布的 HTML5 课件（zip），课堂里直接播放 |
| Scratch 作品 | 上传 sb3 / sb2 / sb，课堂里直接运行演示 |
| 掌控板编程 | 学生拼积木刷进掌控板闯关，教师看板实时看每组进度。学生机需要先运行一次 交付包里的 学生机脚本\配置学生机浏览器.bat |

### 上课（课堂控制台）

开课后进入控制台，学生登录后在首页点“进入课堂”就算签到。控制台各标签：

| 标签 | 能做什么 |
| --- | --- |
| 学生与考勤 | 看每个学生的考勤、机位、进课时间、小组；给课堂得分和评语；“按机位重新分组” |
| 座位图 | 看谁坐在哪、是否已登录；点 ★ 关注学生；按“前10 / 精品 / 待阅”高亮；“管理”后批量暂停 / 恢复网络 |
| 课堂页面 | 逐页“开 / 关”，学生只看得到开放的页面；点页面可以看全班作答、提交和统计 |
| 分组管理 | 设组数、随机分组、加载历史分组、调整组员和组长 |
| 课堂成绩 | 本节课每个学生的课堂表现、测验、作品分，可导出 Excel |
| 作品汇总 | 各作品页的提交数、已批阅数、平均分，按小组统计 |
| 举手与广播 | 处理学生举手、看互助榜、给全班发消息、在线监控（谁在看哪一页） |
| 课堂论坛 | 发帖、回复、置顶、推荐、删帖 |
| 学情监控 | 每个学生在各页面的停留时间 |
| 随机点名 | 滚动点名；登记请假和原因 |

点“下课”可以填本课小结，没进课的学生记为缺席。“上课记录”里可以回看已结束的课堂；“撤销”会清除这节课的全部学习记录，不可恢复。

### 作品批阅

- “作品批阅”列出有待批作品的课堂，点“批阅”进入。
- 逐份批阅：打分、写评语，可“采用自动分”；“发回”让学生重做；“设精华”进入精华作品展。
- 批量操作：“偷懒模式”勾选多份统一打分和评语；“打包下载全部作品”；“循环展播”投屏展示；“按当前规则重新自动评分”。
- 作品提交页的设置（在课程里）：允许的文件类型、同学互看互评、评价量规、学生能否看成绩、是否作为课后操作题开放。
- **自动评分**：给 Word / Excel / PPT / 网页等作品加“评分点”（如某段字体字号、是否有图表、幻灯片切换），上传标准答案点“用标准答案检验”，全部通过再保存。
- “评价量规”菜单：建量规（如 内容 / 技术运用 / 创意，各项分值），可共享。

### 题库、试卷与测验

- **题库**：单选、多选、判断、填空四种题型，可加星级、标签、分类，可共享。导入方式：Excel 模板、题库包、“批量传图入库”（题目截图打 zip，入库后在“待设置答案”里逐题设答案）。删除的题先进回收站。
- **试卷**：从题库添加，或按题型 / 分类 / 星级随机抽题。
- **刷题与分析**：给班级指定刷题题库、看学生刷题情况、错误率报表、题库查重。
- **发布测验 / 布置课后作业**（“作业与测验”菜单）：选试卷、班级和考试方式。
    - 控制模式：学生先“等待开考”，教师点“开考”“结束”（推荐课堂用）。
    - 自动模式：发布后就能作答，教师“停止回收”后统一批改。
    - 提交即批改：交卷就看到得分，适合练习。
    - 可设限时、公布答案时机、题目和选项乱序。
- **测验详情**：成绩表、“查看/改分”、“发还重改”、填空题人工批改、逐题分析、年级统计（及格率 ≥ 60%、优秀率 ≥ 85%）、导出成绩。“结分”后成绩锁定。
- **Python 题库**：写题干、半成品代码和参考代码，加测试点（输入 + 期望输出）；“用参考代码生成期望输出”省去手写。勾选“加入课后题库”学生课后能练。课堂里可“开放参考代码”“重新评测”。

### 班级与学情

| 菜单 | 能做什么 |
| --- | --- |
| 我的班级 | 看学生名单、出席和平均课堂分；添加学生、重置密码、传照片、看单个学生的课堂记录 |
| 学习情况 | 按班级和学期的期末统计：出席、课堂表现、作品、操作题、课后作业、测验；可设总评权重、看名次、导出 Excel |
| 登入记录 | 按班级和日期查学生登录次数、在线分钟和明细 |

### 资料

- **资源库**：上传文件或链接，“分发”给班级后学生在“学习资源”里看；“阅读情况”显示谁读了、读了多久。
- **教案**：写教学设计，附教学资料和课件；可共享、复制，可“打包”后在别的平台“导入教案包”。
- **教师网盘**：不限容量的个人文件空间。

## 六、学生端

学生登录后在“我的课堂”点“进入课堂”就算签到；其余菜单是课后用的学习工具。公开课模式下，有课时登录后直接进入课堂。

### 上课

1. “我的课堂”显示正在上的课，点“进入课堂”。已签到时显示机位和小组，按钮变成“回到课堂”。
2. 左侧是“学习环节”，只列出老师已开放的页面，点哪个看哪个。
3. 各类页面的做法：作品页上传文件（可写作品名、自评、简介，可重新提交）；测验页作答交卷；讨论页在本组发言并提交小组结论；抢答页点“抢 答”；Python 页写代码、“运行”自测、“提交评分”。
4. 课堂里的“举手/消息”：遇到问题举手求助，同学帮你解决后可以“谢谢 TA”；老师的广播消息也在这里。“课堂论坛”可以发帖、回复。
5. 老师下课后课堂变成只读。系统允许补交时，可以从“我的作品”里的“去提交”补交。

### 各菜单

| 菜单 | 能做什么 |
| --- | --- |

| 刷题练习 | 从老师指定题库、自己的错题或全校共享题里抽题练，也可以逐题练；显示累计题数和正确率 |
| Python 练习 | 做老师开放的 Python 课后题，记录最高分 |
| 课后操作题 | 下载素材，按要求做完后上传，系统自动评分，可反复练 |
| 学习资源 | 老师分发的资料，在线阅读或下载；阅读时间会记录 |
| 我的网盘 | 上传、下载自己的文件，容量由系统设置决定；传与学习无关的文件会被老师删除并扣空间 |

## 七、常见问题与注意事项

### 常见问题

| 问题 | 怎么办 |
| --- | --- |
| 学生忘了密码 | 管理员在“用户管理”、或任课教师在“我的班级”里“重置密码” |
| 学生登录页找不到自己的年级或班级 | 检查“年级管理”里该年级是否“启用”，学生是否被设为毕业或停用 |
| 学生正用着电脑突然被提示“已在其他电脑登录” | 系统设置开了“学生单处登录”，有人用同一账号在别处登录了 |
| 固定机位模式下学生登录不了 | 学生没坐在分配给自己的电脑上；或在“固定机位”里重新分配 |
| 学生在课堂里看不到某个页面 | 控制台“课堂页面”里这一页还是“关”，点一下打开 |
| 课堂下不了课 | 管理员在“教学管理 → 当前课堂”里强制下课；还不行用“应急工具 → 全部强制下课” |
| 报表按学期查不到某些课 | “应急工具 → 学期修复”，把没划分学期的课堂归到对应学期 |
| 座位图上断网不起作用 | 先在“系统设置 → 网络控制器”启用并“保存并测试连接”，确认控制器在线。控制器在另一台电脑上时，平台地址和控制器的控制接口地址都不能是 127.0.0.1（分别改成控制器电脑 IP 和 0.0.0.0） |
| 掌控板连不上 | 在学生机上以管理员身份运行一次 交付包里的 学生机脚本\配置学生机浏览器.bat，填教师机地址 |
| 导入时有行失败 | 看结果表里的行号和原因（如学号重复、同班同名），只把这几行改好再导一次 |
| 班级顺序不对 | 在“班级管理”里改“排序”数字 |

### 注意事项

- **不可恢复的操作**：释放毕业生资源空间、应急工具里的全部操作、撤销课堂、彻底删除题目。做之前先备份。
- **备份要备两样**：数据库和交付包里的文件目录 `data/storage`（作品、网盘、课件等上传文件都在这里）。交付包里的 backup.ps1 一次备好两样，见附录。
- **启动平台**：数据库是本机安装的 PostgreSQL 14（开机自动运行）。第一次用记事本把交付包 start.bat 里的 CHANGE_ME 改成数据库密码，之后双击 start.bat 启动，出现 Started IttoolsApplication 就好了；黑窗口要一直开着，服务器重启后要再双击一次。start.bat 实际执行的是 `java -jar ittools.jar`，默认端口 8300。学生机要访问，先以管理员身份运行一次 open-firewall-8300.bat。
- **班内学号超过 99**：用户管理列表排序正常，但课堂名单、报表等处会把 100 号排在 10 号和 11 号之间。
- **权限管理页**：开关重新打开页面后都显示为“开”，不代表已保存的状态。

## 附录：用 DBeaver 管理 PostgreSQL 数据库

推荐用 DBeaver Community：免费、有中文界面，查表、改数据、导出 Excel 和 SQLyog 用法差不多。

### 安装与连接

1. 从 DBeaver 官网下载页（https://dbeaver.io/download/）下载 Windows 版 Community 安装包并安装。
2. 确认 PostgreSQL 14 服务在运行（Windows“服务”里的 postgresql-x64-14，状态为“正在运行”）。DBeaver 可以装在服务器上，也可以装在别的电脑上连过来（主机填服务器 IP，需要服务器放行 5432 端口）。
3. 打开 DBeaver，点左上角“新建数据库连接”（插头图标），选 PostgreSQL。
4. 填写连接参数（见下表），点“测试连接”。第一次会提示下载驱动，点“下载”即可。
5. 显示“已连接”后点“完成”。表在左侧“数据库 → ittools → 模式 → public → 表”下。

| 参数 | 填写 |
| --- | --- |
| 主机 | localhost |
| 端口 | 5432 |
| 数据库 | ittools |
| 用户名 | ittools |
| 密码 | 安装时给 ittools 用户设的密码 |

密码就是安装时给 ittools 用户设的密码，和 start.bat 里的 DB_PASSWORD 一样。连不上时核对 start.bat 里的 `DB_URL`、`DB_USER`、`DB_PASSWORD`。

### 常用表

| 表名 | 内容 |
| --- | --- |
| users | 所有账号（管理员、教师、学生）；xjh 是学号，student_no 是班内学号 |
| school_year | 学年 |
| klass | 班级，display_order 是排序 |
| lesson | 每一次上课（课堂） |
| lesson_attendance | 考勤 |
| login_log | 登录记录 |

### 常用操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 看表里的数据 | 左侧双击表名，切到“数据”标签页 |
| 筛选某些行 | 在数据页顶部的过滤框输条件，如 role = 'STUDENT' and name like '%张%'，回车 |
| 改一个格子 | 双击单元格修改，点底部“保存”（或 Ctrl+S）才会写进数据库；点“取消”放弃 |
| 看表结构 | 双击表名后看“属性”标签页（列、索引、外键），“ER 图”看表之间的关系 |
| 写 SQL 查询 | 右键连接 → “SQL 编辑器” → “新 SQL 脚本”（或 Ctrl+]），写好后 Ctrl+Enter 执行光标所在的一句 |
| 导出成 Excel | 在表或查询结果上右键 → “导出数据” → 选 XLSX → 选保存位置 |

例如查某个班的学生：

```
SELECT u.student_no, u.name, u.xjh
FROM users u JOIN klass k ON k.id = u.class_id
WHERE k.name = '1班' AND u.role = 'STUDENT'
ORDER BY u.student_no;
```

### 备份

推荐用交付包里的 backup.ps1：用记事本把里面的密码改好，右键“使用 PowerShell 运行”。数据库和上传文件会备份到 backup 文件夹，保留 30 天；也可以用“任务计划程序”设成每天自动运行。只想手动备份数据库时，在命令行运行：

```
"C:\Program Files\PostgreSQL\14\bin\pg_dump.exe" -U ittools -h localhost -F c -f ittools_backup.dump ittools
```

按提示输入数据库密码。手动备份时记得同时复制一份 `data/storage` 文件夹。恢复或大量改数据前先停掉平台。

### 注意

- 直接改表会绕过平台的校验（如学号不重复），能在平台里改的尽量在平台里改。
- 不要改或删 `flyway_schema_history` 表，它记录数据库版本，弄坏了平台会启动失败。
- 密码列 password_hash 是加密后的，不能直接改成明文；重置密码请在平台里操作。
