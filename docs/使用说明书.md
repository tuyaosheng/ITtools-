# ITtools 信息技术教学平台 使用说明书

> 本文件是 Word 版 `docs/ITtools使用说明书.docx` 的文字来源，改内容时两边一起更新。

## 一、概述与登录

ITtools 是给信息技术课用的教学平台，分管理员、教师、学生三种角色，三种角色登录后进入各自的后台。浏览器打开平台地址（默认端口 8300）就是登录页。

### 三种角色

| 角色 | 主要工作 | 登录后进入 |
| --- | --- | --- |
| 管理员 | 建年级和班级、导入师生、配置机房、设学期、系统设置 | 管理后台 |
| 教师 | 备课、上课、课堂互动、批作业、出题考试、看学情 | 教师工作台 |
| 学生 | 进课堂学习、交作品、做测验和练习、用网盘和笔记 | 信息课堂 |

### 登录方式

- **学生 · 班级姓名**：选学年、班级、自己的名字，再输密码。
- **学生 · 学号**：输学号和密码。
- **教师 / 管理员**：输账号和密码。
- 登录页显示哪些入口，由“系统设置 → 工作模式”决定：学号模式只显示学号入口；其他模式显示班级姓名入口。
- 学生只能用一种角色入口；进错角色的页面会自动跳回自己的首页。

### 默认密码

| 账号 | 默认密码 | 说明 |
| --- | --- | --- |
| 管理员 admin | admin123 | 初次部署后请立即在右上角“修改密码”中改掉 |
| 学生、教师（新建或导入时没填密码） | 123456 | 管理员可在“用户管理”里逐个重置密码 |

右上角头像菜单里有“个人资料”“修改密码”“退出登录”。学生能否自己改密码、传头像，由系统设置控制。

### 第一次使用的顺序

1. 管理员在“年级管理”建学年（如 2024 级）。
2. 在“班级管理”建班级，或直接用“批量导入”导入学生，年级和班级会自动建好。
3. 在“批量导入”导入教师账号。
4. 在“教学管理”建学期并设为当前学期，把班级绑定给任课教师。
5. 机房上课需要固定座位、开断网的，再配置“机房管理”下的四项。
6. 教师登录，建课程、加页面，然后开课上课。

## 二、管理员 · 师生与班级

这一组菜单管学年、班级和所有账号。新学年开学时，一般只要用“批量导入”导一次学生名单。

### 年级管理

- 每个学年有“学年代码”（入学年份，如 2024）和“学年名称”（如 2024级）。
- 状态设为“停用”后，这个年级不再出现在登录页和教师的班级列表里。
- 年级下还有班级或学生时不能删除。

### 班级管理

- 先在顶部选学年，再新增、编辑、删除班级。
- “排序”决定班级在全系统各处的先后次序，数字小的在前。新增班级时默认排在本年级最后。
- 批量导入自动建的班级，排序取班名里的数字（“3班”排 3）。

### 用户管理

- 列表每页 50 条（可切换 20 / 100 / 200），可按角色、学年、班级筛选，或输姓名 / 学号 / 登录名搜索。
- 新增学生必填姓名和学号；学号全校唯一，学生可用学号登录。班内学号是座号，填正整数，可不填。
- 新增教师、管理员要填登录名。
- 每行可以：编辑、重置密码（至少 6 位）、删除；“毕业”“启用”开关点一下就生效。
- 已经有课程、作业等教学记录的账号不能删除，只能关掉“启用”。
- **兼任管理员**：教师行有“兼任管理员”开关。打开后，这位教师用自己的教师账号登录，教师菜单最下面会多出“⚙ 管理后台”，点进去就能用全部管理功能（用户管理、机位管理、系统设置等），管理后台右上角点“← 返回教师端”回去，不用再换管理员账号。开关改动后，该教师已登录的电脑会下线，重新登录后生效。手机上在用户卡片的“⋯”菜单里设置。
- 为防止没人能进管理后台：不能停用或删除自己的账号、不能改自己的“兼任管理员”，也不能停用或删除最后一个可用的管理员账号。

### 批量导入

1. 点“下载模板”，按模板填表，支持 .xlsx / .xls / .csv。
2. “选择文件”后点“开始导入”。
3. 页面先显示上传百分比，再显示“正在导入 已处理 / 总行数（成功、失败）”的进度条。
4. 导入完成后显示“共 N 行，成功 X，失败 Y”，下面列出每个失败行的行号和原因。改好这几行可以单独再导一次。

| 导入对象 | 必填列 | 可选列 | 注意 |
| --- | --- | --- | --- |
| 学生 | 姓名、学号、年级码（如 2024）、班级（如 1班） | 班内学号、初始密码 | 年级、班级不存在会自动建；学号不能重复；同班不能同名 |
| 教师 | 姓名、登录名 | 初始密码 | 登录名不能重复 |

初始密码留空就是 123456。整个文件出错（例如表头不对）时会显示红色提示，这种情况下一条数据都没有写入。

### 学生数据维护

- **表格批量修改**：选年级 → 下载学生信息表 → 在表里改姓名、学号、班内学号、性别、班级（重新分班）、入学年份或毕业状态 → 上传。系统先列出改动预览，确认后才写入。“编号”列用来对应学生，不要改。
- **批量导入头像**：学生照片按学号命名、教师照片按登录名命名，打成 zip 上传，支持 JPG / PNG / GIF / BMP。结果会列出成功张数和没匹配上的文件名。
- **毕业生管理**：勾选班级后“设为毕业”或“恢复在读”。毕业生不能再登录，也不出现在名单、课堂和报表里。
- **释放资源空间**：删除所选班级毕业生的全部学习记录和文件，只保留账号和精华作品。不可恢复，操作前请先备份数据库。

## 三、管理员 · 机房管理

机房管理的四项按顺序配置：先登记机位（每台电脑），再排机房座位图，再分小组，最后给班级绑定机房和固定座位。不用固定座位、不用开断网的学校可以跳过这一章。

### 机位管理

- 每个机位 = 一台电脑，记录“计算机名”（如 PC-01）和“IP 地址”。
- 可以逐台新增，也可以“下载导入模板”后“批量导入”。导入时可以勾选“导入前清空已有机位”。
- 学生登录时系统按电脑 IP 认出机位，课堂里会显示“机位：PC-xx”。

### 机房模型（座位图）

- **按方案新建**（推荐）：填机房名称、座位名前缀（如 A 或 PC-）、编号位数、1 号座位 IP 和递增/递减方向，再填“共几排、每排几台、每几台留一个过道”和 1 号的位置，点“按这些生成排版”。
- 生成的“排版文本”可以直接改：座位号写数字，过道写 `.`，可以删掉坏机位。下方有预览，最多 40 排、每排 40 个位置。
- **空白新建**：只设行数、列数，再点“调整机位”逐格选电脑，或“按计算机名自动排布”。
- 座位图平时只看；点“管理”后可以点选多个座位，批量“暂停网络 / 恢复网络”；选中两台时可以“交换这两台的 IP”（电脑实际位置和 IP 对不上时用）。
- 开断网和开机状态需要先在“系统设置 → 网络控制器”启用。座位上的 🌐/⛔ 是平台最后一次下发的指令，不是实时探测。
- 每个机房有自己的网络控制器时，点机房的“控制器”填地址和令牌，再点“保存并测试连接”。地址留空的机房、没放进座位图的电脑，都用系统设置里的全局控制器。一台电脑放在多个设了控制器的机房时，用最早建的那个机房的控制器，座位图下方会提示。

### 分组模型

- 把机房里的机位分成若干小组，教师上课时选一个分组模型，学生进课后按自己坐的电脑自动分到对应小组。
- 新增一个分组模型后，填“每组几台”点“自动分组”，也可以在表格里逐台改组号，最后“保存”。

### 固定机位

- 每个班级选“上课机房”，再点“分配座位”给每个学生定一个座位。
- “按班内学号自动分配”会按座号顺序排满，“全部清空”重来。
- 只有系统设置里的工作模式是“班级+姓名+固定机位模式”时，已分配座位的学生才必须在自己的座位上登录。

## 四、管理员 · 系统

开学前必须做的是“教学管理”里的学期和班级绑定；其余项目按需要设置。

### 教学管理

- **学期维护**：新增学期（学年如 2025-2026，学期如 第一学期），点“设为当前”。之后开的课都记在当前学期下，报表按学期筛选。
- **班级绑定教师**：给每个班级选任课教师。教师能开课、看学情的班级 = 绑定给自己的班级 + 还没绑定任何教师的班级；绑给别的老师的班级看不到。
- **当前课堂**：列出正在进行的课（课程、教师、开始时间、出席人数），可以对单个课堂“强制下课”。

### 走班选课

1. “新建选课活动”：填名称、说明，选面向的年级，再逐个“添加科目”（科目名、人数上限、任课教师、上课时间、简介）。
2. 新建后是“草稿”，点“开放选课”后学生在“走班选课”里选、退选、改选，满额的科目选不了。
3. 点“结束选课”后名单固定；“名单”查看、“导出”得到 Excel。

### 权限管理

按模块列出系统权限（如用户管理、班级管理、年级管理、权限管理），可以逐项关闭。一般保持全部开启即可。

### 系统设置

| 分组 | 设置项 | 说明 |
| --- | --- | --- |
| 基本 | 学校名称 | 显示在登录页和各端左上角 |
| 基本 | 工作模式 | 正常教学：班级+姓名+密码登录；公开课：学生登录后直接进入当前课堂；学号+密码：只显示学号登录；固定机位：已分配座位的班级必须在自己的座位登录 |
| 文件 | 禁止上传的扩展名 | 逗号分隔，如 exe,bat |
| 文件 | 单文件上限、学生网盘容量 | 单位 MB |
| 文件 | 学生单处登录 | 开启后同一个学生账号同一时间只能在一台电脑上登录。“重复登录时”二选一：**新登录让旧电脑下线**（默认）；**先登录的占用，别的电脑登不上**（同一台电脑关了浏览器、重启后可重新登录；学生要换电脑时老师点“强制下线”，学生点“退出”或关浏览器约 30 分钟后也会放开） |
| 教学 | 允许作业补交 | 下课后学生还能交作品，标记为“补交” |
| 教学 | 敏感词过滤 | 多个用逗号分隔 |
| 登录页与学生权限 | 登录页公告、班级姓名免密登录、学生改密码、学生传头像 | “班级姓名免密登录”开启后，学生在登录页选学年、班级、姓名直接点登录，不用输密码（学号登录、教师、管理员仍要密码）；其余开关控制学生能否自己改 |
| 第三方程序登录 | 开启、签名密钥 | 其他系统带签名链接让学生免密登录；链接 5 分钟内有效且只能用一次，生成新密钥后旧密钥立即失效 |
| 内置 MQTT 服务器 | 开关、端口、账号、密码 | 代替单独运行的 SIoT（默认 1883、siot / dfrobot，Mind+ 里物联网平台照样选 SIoT）。每节课开课时自动生成项目名（B+班级号_月日_时分，如 B81_1115_0820），主题写成“项目名/设备名”；消息按课堂分开保存，不用下课清理。旁边显示运行状态；本机还开着 SIoT 会占用端口，要先关掉。防火墙要放行该端口 |
| 网络控制器（CTR） | 启用、控制器地址、访问令牌 | 启用后机房座位图能批量开网 / 断网。控制器和平台在同一台电脑时地址填 http://127.0.0.1:8770；不在同一台时填 http://控制器电脑IP:8770，并把控制器的控制接口地址（api_host）改成 0.0.0.0、那台电脑防火墙放行 8770、两边填同一个令牌；点“保存并测试连接”会显示被控端台数和在线台数 |

改完点“保存设置”才生效。

### 应急工具（操作不可撤销）

| 工具 | 什么时候用 |
| --- | --- |
| 全部强制下课 | 正常下课和单个强制下课都不管用时，把所有进行中的课堂一次关掉；没进课的学生记为缺席 |
| 消除缺勤记录 | 学生补了假条、或后来才转入本班：选年级、班级查询后勾选缺席 / 请假记录删除，这节课不再计入出勤统计 |
| 学期修复 | 调整过学期后，有些课堂没归到任何学期，报表按学期查不到：查出这些课堂，指定学期 |
| 强制删除课程 | 删除已经开过课的课程，连同全部课堂和学习记录（考勤、作品、测验）。教师自己只能删没开过课的课程。删前先备份数据库 |

## 五、教师端

教师的日常是三步：在“我的课程”备课，点“开课”进入课堂控制台上课，下课后在“作品批阅”“作业与测验”“学习情况”里收尾。

### 工作台

- 显示当前学期、正在进行的课堂、最近上课记录和今日课表。
- “开 课”：选课程、上课班级、分组模型（可不分组），点“开始上课”。
- 课表在“课表”菜单里编辑：按星期和节次填写（如班级名），节数可调，保存后工作台显示当天的课。

### 我的课程（备课）

1. “新建课程”，在“属性”里设分类、学期、简介，打开“共享”后其他老师能在“共享课程 / 模板”里看到并“以此为模板新建”。
2. 进入课程，“添加页面”，选页面类型、填标题和内容，“保存页面”后再上传附件或做专属设置。
3. 勾选“默认隐藏”的页面，上课时要教师手动打开学生才看得到。
4. 课程可以“复制”“导出”（课程包），也可以“导入课程包”。没开过课的课程可以删除。
5. 不再用的课程点“归档”：归档的课程不在“我的课程”列表里，开课选课程时也不出现，也不能用它开课；勾选“显示已归档”能看到，点“取消归档”恢复。归档不动课程页面、上课记录和学生提交。
6. 页面正文可以写占位符，课堂里按本节课替换：`{{MQTT项目}}`（本节课的 MQTT 项目名）、`{{服务器IP}}`（学生打开平台用的地址）、`{{媒体:文件名}}`（课程包 `media/` 目录里的文件，如操作视频 `<video src="{{媒体:步骤1.mp4}}" controls>`）。和学生所在小组有关的：`{{组名}}`（如 门铃3组）、`{{组号}}`、`{{角色}}`（如 门铃）、`{{配对号}}`（如 3），每个学生看到的是自己组的，例如主题写成 `{{MQTT项目}}/Bell{{配对号}}`。课程编辑里看到的是原文。
7. 页面的“给哪些组看”：不选是全班都看；选了角色（如“只给门铃组”），只有课堂分组里设成这个角色的组看得到这一页，成绩开网也只要求这些组完成这一页。课程复制、课程包导出导入都会带上这个设置。

| 页面类型 | 用途 |
| --- | --- |
| 图文 | 文字、图片等学习内容 |
| 资料课件 | 上传 PPT / Word / Excel / PDF / 图片等，课堂里直接显示，同时可下载。**PPT 动画模式**（服务器装了 LibreOffice 时默认）：保留动画和切换效果，点幻灯片、按 → / 空格或点“下一步”播放下一个动画，“«”“»”或 PageUp / PageDown 直接翻页（跳过本页剩下的动画），工具栏显示第几页；“全屏播放”铺满屏幕，Esc 退出。常见的进入、退出、强调、切换效果都能播放；动画加在“组合”里面单个形状上的（如整张思维导图逐个出现），会整体显示、点击没有变化，这类页用“»”翻过去即可。**图片模式**：每张幻灯片一张图，不播动画，显示最稳定，可随时点“图片模式 / 动画模式”切换；服务器没装 LibreOffice 时自动用图片模式。Word、Excel 直接显示，多个工作表可切换。第一次打开大课件要等几秒生成，之后直接显示；需要和 Office 完全一样时点“下载” |
| 视频 | 上传视频或填视频地址 |
| 外部网页 | 嵌入或打开一个网址 |
| 作品提交 | 学生上传作品，可自动评分、互评。打开“图形化编程”后，学生直接在这一页里用平台的图形化编程（掌控板）拼积木、上传到掌控板、提交作品（见下面“图形化编程（掌控板）”） |
| 课堂测验 | 关联题库试卷，学生在线作答、自动批改 |
| 讨论 | 按小组讨论并提交小组结论 |
| 抢答 | 教师发起抢答，学生抢先作答，教师判定对错 |
| Python 操作题 | 学生在线写 Python，按测试点自动评分 |
| 分组与组长 | 学生自由选小组、推选组长 |
| 小组合作 | 研究主题、组内分工、资源交流、组员互评，组长提交成果 |
| 小组成果展示 | 展示各组成果，组间互评 |
| 课堂调查 | 判断 / 单选 / 多选 / 填空调查，实时统计全班和年级结果 |
| 随机抽题 | 学生随机抽一道问题，相邻座号的同学题目不同 |
| 课件包 | 上传 Storyline 等发布的 HTML5 课件（zip），课堂里直接播放 |
| Scratch 作品 | 上传 sb3 / sb2 / sb，课堂里直接运行演示 |
| 掌控板编程 | 学生拼积木刷进掌控板闯关，教师看板实时看每组进度。学生机需要先运行一次 交付包里的 学生机脚本\配置学生机浏览器.bat |
| 物联网消息 | 显示掌控板等设备发到内置 MQTT 服务器的消息：本节课的项目名、各设备最近的消息，本组排最前；每 3 秒刷新 |

### 上课（课堂控制台）

开课后进入控制台，学生登录后在首页点“进入课堂”就算签到。控制台各标签：

| 标签 | 能做什么 |
| --- | --- |
| 学生与考勤 | 看每个学生的考勤、机位、进课时间、小组；给课堂得分和评语；“按机位重新分组”；每个学生可以重置密码、强制下线（手机上在学生卡片右边的“⋯”里） |
| 座位图 | 看谁坐在哪、是否已登录；点 ★ 关注学生；按“前10 / 精品 / 待阅”高亮；“管理”后批量暂停 / 恢复网络 |

| 分组管理 | 设组数和每组人数（0 为不限），点“开放选组”后学生自己选组，开放期间可以随时换组或退出，满员的组加不进；点“关闭选组”后学生不能再加入或换组。成绩开网要求小组全员完成时，学生进组后不能自己换组。另有随机分组、加载历史分组、调整组员和组长（老师调人不受人数限制）。“更多操作 → 按学号分组”：全班（含没进课的）按学号每组几人，挨着排（1-2-3、4-5-6）或间隔排（45 人 15 组时 1、16、31 一组），没进课的进课后自动在组里。“小组角色”：填“门铃,显示”点“一键生成”，按组号排成 门铃1~N组、显示1~N组，同一配对号的两组是一对；组数凑不成对时，多出来的组并进前面的对（几组共用一个主题）；组卡片上点“角色”可以改角色、配对号或直接改组名；打开“学生整组选角色”后学生在选组页里整组选角色和配对号（同一角色同一个号只能一个组选）；“按对”可以看每一对有哪些组 |
| 课堂成绩 | 本节课每个学生的课堂表现、测验、作品分，可导出 Excel |
| 作品汇总 | 各作品页的提交数、已批阅数、平均分，按小组统计 |
| 举手与广播 | 处理学生举手、看互助榜、给全班发消息、在线监控（谁在看哪一页） |
| 课堂论坛 | 发帖、回复、置顶、推荐、删帖 |
| 学情监控 | 每个学生在各页面的停留时间 |
| 随机点名 | 滚动点名；登记请假和原因 |
| 物联网消息 | 本节课 MQTT 项目下各设备的消息；内置服务器没运行时显示原因；可清空本课消息、从网页往某个设备发一条消息（测试订阅用）。点“投屏大屏”在新窗口打开大屏：每台设备一块，最新消息放大显示，新消息到了闪一下，一直发数字的设备画出变化曲线，G03 这样的设备显示组名；可以“按配对”把同一对的设备排在一起，A-/A+ 调字号，“从现在开始看”只显示之后的消息，深色/浅色，全屏；鼠标不动 5 秒按钮自动隐藏 |
| 成绩开网 | 选一个测验并填达标分，可再勾选必须完成的作品页和作品达标分、必须提交的任务单（课堂调查页，只看交没交）；全部达标的学生自动开网，其余按“没达标时”的选择处理：白名单（默认，只能上网络控制器 CTR“规则管理 → 白名单”里放行的网站；名单为空或 CTR 版本太旧时自动改为断网）或断网（老师手动“断网”的学生始终是断网）；可打开“小组全员完成才开网”（同组出席的人都达标才一起开网，没进组的不开网），再打开“作品组内有人交就算”时，每个作品页组里有一人达标即可，测验和任务单仍要每人完成；页面设了“只给某角色的组看”时，别的角色的组不用做那一页（名单里显示“不用做”）；可打开“本对各组都完成才开网”（门铃N组和显示N组都完成才一起开网，名单状态显示“等搭档组”，下面按对列出每组还差什么）；可加机会、手动放行。需要网络控制器，下课后自动恢复 |

点“下课”可以填本课小结，没进课的学生记为缺席。“上课记录”里可以回看已结束的课堂；“撤销”会清除这节课的全部学习记录，不可恢复。

下错课或课没上完，可以在“上课记录”或该课的控制台点“重新开课”：课堂回到上课状态，学生的提交、成绩、分组都保留，下课时自动记的缺席会去掉（老师手动记的请假不动），下课时自动关掉的成绩开网会重新打开。同一个班已经有一节课在上时不能重开，要先下课。

### 作品批阅

- “作品批阅”列出有待批作品的课堂，点“批阅”进入。
- 逐份批阅：打分、写评语，可“采用自动分”；“发回”让学生重做；“设精华”进入精华作品展。
- 批量操作：“偷懒模式”勾选多份统一打分和评语；“打包下载全部作品”；“循环展播”投屏展示；“按当前规则重新自动评分”。
- 作品提交页的设置（在课程里）：允许的文件类型、同学互看互评、评价量规、学生能否看成绩、是否作为课后操作题开放。
- **自动评分**：给 Word / Excel / PPT / 网页等作品加“评分点”（如某段字体字号、是否有图表、幻灯片切换），上传标准答案点“用标准答案检验”，全部通过再保存。Mind+ 程序（.mp / .mpcode，平台图形化编程交的也是 .mpcode）有“使用了积木”“积木放在指定积木里面”“比较积木已填入数值”“填写了数值或文字”“MQTT 设置正确（平台、服务器、主题）”。“MQTT 设置正确”的主题可以写占位符 `{{MQTT项目}}` `{{配对号}}` `{{组号}}` `{{角色}}`，按每个学生替换，如 `{{MQTT项目}}/Bell{{配对号}}`：第 3 对的学生要写 本节课项目名/Bell3 才得分。
- “评价量规”菜单：建量规（如 内容 / 技术运用 / 创意，各项分值），可共享。

### 题库、试卷与测验

- **题库**：单选、多选、判断、填空四种题型，可加星级、标签、分类，可共享。导入方式：Excel 模板、题库包、“批量传图入库”（题目截图打 zip，入库后在“待设置答案”里逐题设答案）。删除的题先进回收站。
- **试卷**：从题库添加，或按题型 / 分类 / 星级随机抽题。“从题库添加”可以按分类（如 第11课）、题型、标签筛选和搜索题干，点一题加入，或点“全部加入”把筛出来的题一次加进试卷；鼠标停在题干上能看到全文。学生的得分和满分按试卷里每题的分值计算，课堂测验页只显示试卷总分。
- **刷题与分析**：给班级指定刷题题库、看学生刷题情况、错误率报表、题库查重。
- **发布测验 / 布置课后作业**（“作业与测验”菜单）：选试卷、班级和考试方式。
    - 控制模式：学生先“等待开考”，教师点“开考”“结束”（推荐课堂用）。
    - 自动模式：发布后就能作答，教师“停止回收”后统一批改。
    - 提交即批改：交卷就看到得分，适合练习。
    - 可设限时、公布答案时机、题目和选项乱序。
- **测验详情**：成绩表、“查看/改分”、“发还重改”、填空题人工批改、逐题分析、年级统计（及格率 ≥ 60%、优秀率 ≥ 85%）、导出成绩。“结分”后成绩锁定。
- **Python 题库**：写题干、半成品代码和参考代码，加测试点（输入 + 期望输出）；“用参考代码生成期望输出”省去手写。勾选“加入课后题库”学生课后能练。课堂里可“开放参考代码”“重新评测”。

### 图形化编程（掌控板）

平台自带的图形化编程，积木的样子、分类、参数和 Mind+ 2.0.7 上传模式的“掌控板”“Wi-Fi”“MQTT”一样（共 126 个）。上传到掌控板有两种方式，编辑器顶上的下拉框可以选，默认是“Mind+ 方式”：

| 上传方式 | 怎么工作 | 学生机要准备 | 掌控板 |
|---|---|---|---|
| **Mind+ 方式（本机编译）** | 和 Mind+ 上传模式一样生成 C++，用这台学生机上 Mind+ 自带的编译工具编译后写进掌控板。一次约 15～30 秒（每台电脑第一次编译慢些） | 装好 Mind+（下载过掌控板和网络扩展），打开“ITtools掌控板助手” | 不用动，和平时用 Mind+ 一样 |
| **MicroPython 方式** | 生成 MicroPython，浏览器直接通过 USB 线写进掌控板，几秒钟 | Chrome/Edge，运行过一次“配置学生机浏览器.bat” | 要先刷一次 MicroPython 固件；用 Mind+ 上传过程序后要再刷 |

下拉框里还有“自动”：这台电脑上的掌控板助手开着就用 Mind+ 方式，没开就用 MicroPython 方式。学生改过的选择会记在这台电脑的浏览器里。选了“Mind+ 方式”时，右边代码区显示的就是 Mind+ 上传模式会生成的 C++（去掉了注释）。

- **学生随时练习**：学生左侧菜单“图形化编程”随时能打开（不用在课里），程序自动保存到平台（每人一份，换电脑登录也能接着做），也能另存为 .mpcode。管理员可以在“功能开关”里关掉这个菜单。
- **配套任务单（一页里边看边做）**：作品页打开“图形化编程”后，设置里多了“旁边显示任务单”，从本课程里选一个“课堂调查”（任务单）或“图文”页。学生打开作品页时，左边拼积木、上传，右边一栏就是任务单（步骤、填读数、选择题），可以直接填写提交，右上角能收起；点“全屏”编辑器和任务单一起铺满屏幕，做实验时推荐全屏。任务单页按标题关联，复制课程、导出导入课程包后还能对上；改了任务单标题要重新选。上课时任务单那一页也要打开，学生才能填写（没打开时右边只显示标题和提示）。
- **起始程序、接着上节课做**：作品页打开“图形化编程”后，设置里还有“起始程序”和“以前的程序”。点“设置起始程序”会打开编辑器，直接搭好（自动保存），或在编辑器里点“打开”载入 .mpcode（Mind+ 做的也行）；门铃组、显示组的作品页各配一份，就是按角色不同。学生第一次打开这一页（本节课还没存过）时会弹出“从哪里开始？”：老师给的起始程序 / 我以前的程序（别的课的作品页、“图形化编程”随时练习、交过的 .mpcode 作品，带课程名、页面名和时间）/ 空白，选好以后就自动保存在这一页。做到一半也能点编辑器的“打开”换成这些程序（会替换现在的积木）。不想让学生用以前的程序，就取消“允许学生选用自己以前的程序”。起始程序和这个开关会随复制课程、课程包一起带走。
- **在课里用**：在课程里建“作品提交”页，页面设置打开“图形化编程”。学生打开这一页就是编辑器：拼积木 →“上传到设备”（MicroPython 方式要先点“连接设备”），做好了点右上角“提交作品”（交的是 .mpcode，Mind+ 能直接打开）。程序自动保存，下节课打开同一页面接着做。页面也可以设“只给某角色的组看”。
- **掌控板助手（Mind+ 方式用）**：交付包 学生机脚本\ITtools掌控板助手.exe，复制到每台学生机（不用安装、不用管理员），第一次打开在窗口里填教师机地址（如 192.168.1.10:8300）点“保存”，再勾“开机在后台自动运行”：以后学生机一开机助手就在后台运行，不弹窗口、不占任务栏，只在屏幕右下角托盘里有个图标（鼠标停在图标上能看到是否连上教师机）。单击托盘图标打开窗口；关掉窗口助手仍在后台运行，右键托盘图标选“退出助手”才真正退出；助手已经在后台时再双击 exe，也是把窗口叫出来。没填教师机地址时，开机会照样弹出窗口让人填。Mind+ 装在哪个盘、哪个文件夹都可以：助手先看安装登记，再看正在运行的 Mind+、桌面和开始菜单的快捷方式、各盘根目录和下一层文件夹，找到后记住；实在找不到就点“选择 Mind+ 位置”选 Mind+ 的安装文件夹（里面有 Mind+.exe）。编译用的是这台电脑当前账号的 Mind+ 数据（%LOCALAPPDATA%\mind+\Arduino，第3课的离线包放的就是这里）。窗口里能看到：是否连上教师机、是否找到 Mind+、掌控板插在哪个串口。助手只读 Mind+ 的文件，不改 Mind+ 的设置；编译的临时文件在 %LOCALAPPDATA%\ITtools掌控板助手。网页上占着串口（MicroPython 方式点过“连接设备”）时会先自动断开再上传；Mind+ 本身开着并连着板子时要先在 Mind+ 里断开。
- **MQTT 初始化参数**：点积木上的齿轮，平台选 SIoT，服务器地址、本节课的项目名会自动给出，下面有“填入 项目名/G03”“填入 项目名/Bell3”这样的按钮。主题都写成“项目名/设备名”。
- **老师看**：作品批阅里 .mpcode 作品旁边有“看积木”，用只读的编辑器打开；还没交的学生点“看拼到哪了”看他自动保存的积木。老师也可以把学生的程序上传进自己的掌控板试（教师机开着掌控板助手就用 Mind+ 方式）。
- **删除积木**：和 Mind+ 一样，把积木拖到左边的分类栏或积木区，出现半透明遮罩和垃圾桶时松手就删掉了；也可以拖到右下角的垃圾桶。
- **打开、另存为**：可以打开电脑里的 .mpcode（Mind+ 做的也行），也可以另存为 .mpcode，Mind+ 能直接打开。下方“串口”显示上传过程和（MicroPython 方式时）掌控板打印的内容；Mind+ 方式暂时看不到掌控板的串口输出，要看请用 Mind+ 的串口监视。
- **刷固件（MicroPython 方式用）**：Mind+ 上传模式刷过程序的掌控板里没有 MicroPython 了，要先刷一次：点“刷固件”，选掌控板的 mPython 固件（.bin），点“开始刷”。选过的固件存在这台电脑的浏览器里，下一块板子直接点“开始刷”。连不上时按住板子背面的 BOOT 键再点。
- **浏览器**：要用 Chrome 或 Edge。MicroPython 方式要先以管理员身份运行一次交付包里的 学生机脚本\配置学生机浏览器.bat（和“掌控板编程”页一样）；Mind+ 方式不需要。

## 六、学生端

学生登录后在“我的课堂”点“进入课堂”就算签到；其余菜单是课后用的学习工具。公开课模式下，有课时登录后直接进入课堂。

### 上课

1. “我的课堂”显示正在上的课，点“进入课堂”。已签到时显示机位和小组，按钮变成“回到课堂”。
2. 左侧是“学习环节”，只列出老师已开放的页面，点哪个看哪个。
3. 各类页面的做法：作品页上传文件（可写作品名、自评、简介，可重新提交）；测验页作答交卷；讨论页在本组发言并提交小组结论；抢答页点“抢 答”；Python 页写代码、“运行”自测、“提交评分”。
4. 课堂里的“举手/消息”：遇到问题举手求助，同学帮你解决后可以“谢谢 TA”；老师的广播消息也在这里。“课堂论坛”可以发帖、回复。
5. 选组页（分组与组长）：老师打开“学生整组选角色”后，组里任何一个人选“门铃组/显示组”和配对号，全组都是这个角色，组名变成“门铃3组”这样；同一角色同一个号只能一个组选。
6. 老师设置了成绩开网时，左侧第一项是“完成情况”：列出自己还差什么（测验没做或分数不够、哪个作品还没交或分数不够、哪个任务单还没提交）；要求小组全员完成时，还能看到同组每个人的完成情况和“本组还差”的作品，每 5 秒自动刷新；有配对时还列出搭档组（如显示3组）每个人还差什么。
7. 老师下课后课堂变成只读。系统允许补交时，可以从“我的作品”里的“去提交”补交。

## 七、常见问题与注意事项

### 常见问题

| 问题 | 怎么办 |
| --- | --- |
| 学生忘了密码 | 管理员在“用户管理”、或任课教师在“我的班级”里“重置密码” |
| 学生登录页找不到自己的年级或班级 | 检查“年级管理”里该年级是否“启用”，学生是否被设为毕业或停用 |
| 学生正用着电脑突然被提示“已在其他电脑登录” | 系统设置开了“学生单处登录”（新登录让旧电脑下线），有人用同一账号在别处登录了；想让后登录的人登不上，把“重复登录时”改成“先登录的占用” |
| 学生登录时提示“这个账号已在 某 IP 上登录” | 开了“先登录的占用”，账号还在另一台电脑上在线：确认是本人换电脑后，老师在“我的班级”或课堂控制台的考勤表里点“强制下线”，再让学生登录 |
| 固定机位模式下学生登录不了 | 学生没坐在分配给自己的电脑上；或在“固定机位”里重新分配 |
| 学生在课堂里看不到某个页面 | 控制台“课堂页面”里这一页还是“关”，点一下打开 |
| 课堂下不了课 | 管理员在“教学管理 → 当前课堂”里强制下课；还不行用“应急工具 → 全部强制下课” |
| 报表按学期查不到某些课 | “应急工具 → 学期修复”，把没划分学期的课堂归到对应学期 |
| 座位图上断网不起作用 | 先在“系统设置 → 网络控制器”启用并“保存并测试连接”，确认控制器在线；机房单独设了控制器的，到机房的“控制器”里测试。控制器在另一台电脑上时，平台地址和控制器的控制接口地址都不能是 127.0.0.1（分别改成控制器电脑 IP 和 0.0.0.0） |
| 掌控板连不上 | MicroPython 方式：在学生机上以管理员身份运行一次 交付包里的 学生机脚本\配置学生机浏览器.bat，填教师机地址；Mind+ 方式：看学生机上的掌控板助手窗口（教师机地址、Mind+、串口三行） |
| 图形化编程显示“没有打开掌控板助手” | 看学生机右下角托盘里有没有助手图标（可能被收进“^”里）；没有就打开 学生机脚本\ITtools掌控板助手.exe，填好教师机地址并勾“开机在后台自动运行”，或者在编辑器顶上把上传方式换成“MicroPython 方式” |
| 导入时有行失败 | 看结果表里的行号和原因（如学号重复、同班同名），只把这几行改好再导一次 |
| 班级顺序不对 | 在“班级管理”里改“排序”数字 |

### 注意事项

- **不可恢复的操作**：释放毕业生资源空间、应急工具里的全部操作、撤销课堂、彻底删除题目。做之前先备份。
- **备份要备两样**：数据库和交付包里的文件目录 `data/storage`（作品、网盘、课件等上传文件都在这里）。交付包里的 backup.ps1 一次备好两样，见附录。
- **启动平台**：数据库是本机安装的 PostgreSQL 14（开机自动运行）。第一次用记事本把交付包 start.bat 里的 CHANGE_ME 改成数据库密码，之后双击 start.bat 启动，出现 Started IttoolsApplication 就好了；黑窗口要一直开着，服务器重启后要再双击一次。start.bat 实际执行的是 `java -jar ittools.jar`，默认端口 8300。学生机要访问，先以管理员身份运行一次 open-firewall-8300.bat。
- **PPT 动画显示（可选，推荐）**：在服务器上安装 LibreOffice（免费，官网 zh-cn.libreoffice.org 下载 Windows x86-64 安装包，可拷到 U 盘离线安装，一路默认装到 C:\Program Files\LibreOffice），装好后重启平台，资料课件里的 PPT 就能按原动画播放。装在别的位置时，在 start.bat 里加一行 `set SOFFICE_PATH=D:\...\program\soffice.exe`。不装也能用，PPT 按图片显示。
- **班内学号超过 99**：用户管理列表排序正常，但课堂名单、报表等处会把 100 号排在 10 号和 11 号之间。
- **权限管理页**：开关重新打开页面后都显示为“开”，不代表已保存的状态。

## 附录：用 DBeaver 管理 PostgreSQL 数据库

推荐用 DBeaver Community：免费、有中文界面，查表、改数据、导出 Excel 和 SQLyog 用法差不多。

### 安装与连接

1. 从 DBeaver 官网下载页（https://dbeaver.io/download/）下载 Windows 版 Community 安装包并安装。
2. 确认 PostgreSQL 14 服务在运行（Windows“服务”里的 postgresql-x64-14，状态为“正在运行”）。DBeaver 可以装在服务器上，也可以装在别的电脑上连过来（主机填服务器 IP，需要服务器放行 5432 端口）。
3. 打开 DBeaver，点左上角“新建数据库连接”（插头图标），选 PostgreSQL。
4. 填写连接参数（见下表），点“测试连接”。第一次会提示下载驱动，点“下载”即可。
5. 显示“已连接”后点“完成”。表在左侧“数据库 → ittools → 模式 → public → 表”下。

| 参数 | 填写 |
| --- | --- |
| 主机 | localhost |
| 端口 | 5432 |
| 数据库 | ittools |
| 用户名 | ittools |
| 密码 | 安装时给 ittools 用户设的密码 |

密码就是安装时给 ittools 用户设的密码，和 start.bat 里的 DB_PASSWORD 一样。连不上时核对 start.bat 里的 `DB_URL`、`DB_USER`、`DB_PASSWORD`。

### 常用表

| 表名 | 内容 |
| --- | --- |
| users | 所有账号（管理员、教师、学生）；xjh 是学号，student_no 是班内学号 |
| school_year | 学年 |
| klass | 班级，display_order 是排序 |
| lesson | 每一次上课（课堂） |
| lesson_attendance | 考勤 |
| login_log | 登录记录 |

### 常用操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 看表里的数据 | 左侧双击表名，切到“数据”标签页 |
| 筛选某些行 | 在数据页顶部的过滤框输条件，如 role = 'STUDENT' and name like '%张%'，回车 |
| 改一个格子 | 双击单元格修改，点底部“保存”（或 Ctrl+S）才会写进数据库；点“取消”放弃 |
| 看表结构 | 双击表名后看“属性”标签页（列、索引、外键），“ER 图”看表之间的关系 |
| 写 SQL 查询 | 右键连接 → “SQL 编辑器” → “新 SQL 脚本”（或 Ctrl+]），写好后 Ctrl+Enter 执行光标所在的一句 |
| 导出成 Excel | 在表或查询结果上右键 → “导出数据” → 选 XLSX → 选保存位置 |

例如查某个班的学生：

```
SELECT u.student_no, u.name, u.xjh
FROM users u JOIN klass k ON k.id = u.class_id
WHERE k.name = '1班' AND u.role = 'STUDENT'
ORDER BY u.student_no;
```

### 备份

推荐用交付包里的 backup.ps1：用记事本把里面的密码改好，右键“使用 PowerShell 运行”。数据库和上传文件会备份到 backup 文件夹，保留 30 天；也可以用“任务计划程序”设成每天自动运行。只想手动备份数据库时，在命令行运行：

```
"C:\Program Files\PostgreSQL\14\bin\pg_dump.exe" -U ittools -h localhost -F c -f ittools_backup.dump ittools
```

按提示输入数据库密码。手动备份时记得同时复制一份 `data/storage` 文件夹。恢复或大量改数据前先停掉平台。

### 注意

- 直接改表会绕过平台的校验（如学号不重复），能在平台里改的尽量在平台里改。
- 不要改或删 `flyway_schema_history` 表，它记录数据库版本，弄坏了平台会启动失败。
- 密码列 password_hash 是加密后的，不能直接改成明文；重置密码请在平台里操作。
