# ITtools 新平台测试手册

本手册带你在**本机演示环境**里把新平台完整走一遍。演示环境用单独的数据库（`ittools_demo`）和单独的文件目录（`data\demo-storage`），随便测，不会影响开发数据，测乱了可以一键重置。

---

## 一、准备（约 3 分钟）

### 1. 启动

前提：**Docker Desktop 已运行**（数据库在 Docker 里；Python 题服务器评测也用 Docker）。

| 步骤 | 操作 |
|---|---|
| ① 启动服务器 | 双击 `ittools\scripts\demo\start-demo.bat`，看到 `Started IttoolsApplication` 后不要关闭这个窗口 |
| ② 填充演示数据（只需一次） | 双击 `ittools\scripts\demo\seed-demo.bat`，最后显示“✓ 演示数据准备完成” |
| ③ 打开 | 浏览器访问 **http://localhost:8300** |

- 停止：在服务器窗口按 `Ctrl+C`。下次再测直接做 ①，数据还在。
- 重来：先停止服务器，双击 `reset-demo.bat` 清空，再做 ① ②。
- 用机房其他电脑测试：把地址换成 `http://本机IP:8300`（Windows 防火墙需放行 8300 端口）。

> 提示：服务器的 jar 已经打包好（`ittools-app\target\ittools-app-0.1.0-SNAPSHOT.jar`）。如果之后改了代码，需要重新打包才会生效。

**附：生成第三方登录链接**（把密钥换成系统设置里显示的值）

```python
import hmac, hashlib, time
secret = "这里粘贴密钥"
u, t = "S20260101", int(time.time())
s = hmac.new(secret.encode(), f"{u}|{t}".encode(), hashlib.sha256).hexdigest()
print(f"http://localhost:8300/api/auth/sso?u={u}&t={t}&s={s}")
```

## 三、说明与已知限制

- **Python 服务器评测需要 Docker**：Docker Desktop 没开时，学生页面内的“运行”（浏览器内执行）仍可用，但“提交”评测会失败。
- **座位图、机位绑定**需要真实机房 IP，演示环境（一台电脑）里所有学生显示为同一台电脑，无法体现座位。
- **Storyline / Scratch** 演示数据里只建了空页面，需要你上传自己的课件或作品。
- 学生网站、课件包在隔离环境里运行（不能读取平台登录信息）。个别依赖本地存储的课件播放异常时，可在课件包设置中开启“兼容模式”。
- 页面停留时间、阅读时间只在浏览器窗口处于前台时计时。
- 班内学号可以超过 50；但超过 99 时，课堂名单、报表等处会把 100 号排在 10 号和 11 号之间（用户管理列表排序正常）。
- 发现问题时，请记下：**用例编号、账号、操作步骤、看到的提示**（截图更好），我据此排查。
